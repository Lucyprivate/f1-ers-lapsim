# 第三阶段车辆精度与跨会话验收

本项目将真实驾驶输入重放与模型自主预测分别验收。第三阶段独立保存在 `f1-ers-lab-v3`，新增代码位于 `f1ers_v3`。原第二阶段项目、缓存、测试访问记录及下载包保持原样。当前精度结论以 `results/austria_2026_v3/summary.json` 和自包含 `report.html` 为准。

本轮三个候选均未通过双路径验收，跨会话测试待完成，正式训练暂停。实际数值、预算和失败位置见 [RESULTS_V3.md](RESULTS_V3.md)。第二阶段的散列复核入口仍为原 `f1-ers-lab` 项目及v2下载包；本目录中的旧结果供历史查看。

## 模型和数据

车辆步进统一使用有符号轮端力，检查速度、时间、轮胎纵横向力预算及机械功守恒。重放按模拟时间读取观测油门与刹车开关；油门线性插值，刹车前值保持。完整圈只使用一次观测初始速度，途中不重置速度，也不以未来速度包络强制制动。等效动力及制动不代表真实赛车的动力分配；重放 SOC 和 MGU-K 字段不适用，`ers_validated=false`。

自主驾驶器按固定几何生成动力和制动需求，ERS 控制使用因果保护、2 MJ 电量下限和降功率储备。再生和摩擦制动共享轮胎力预算。固定驾驶输入的网格检查保留真实轮胎及能量限制；重新计算的未来制动包络只作诊断，避免改变冻结的驾驶需求。

三个候选依次为输入和对齐修正、周期样条几何、纵横向能力分离。周期样条以解析曲率及真实弧长重采样，检查闭环、连续曲线边界和规则坐标映射。仍使用二维固定路线，没有加入自由赛车线、复杂轮胎或大型优化框架。方法来源和适用范围见 [SOURCES_V3.md](SOURCES_V3.md)。

## 校准和冻结协议

正赛第3至6圈用于拟合，第7和9圈用于开发选择。第10至12圈属于已经评分的历史诊断，不能作为新测试。坐标配准、控制线相位及时间偏移只从校准圈估计；开发圈不按速度残差移动曲线。

每个候选使用三个固定起点，各最多300次迭代和600次评估。共享参数为摩擦系数、阻力面积和下压力面积；重放另拟合等效最大动力350至732.5 kW。纵横向分离候选另拟合全局制动比例0.5至1.2。没有逐弯参数。失败圈保留轨迹和保护原因，仅用于可行性搜索，不计算部分圈精度。没有完整参考时，近优族或灵敏度明确标记不可用。

只有收敛、完整且物理可行的候选参加开发选择。两条路径的归一化速度、圈时和分段误差等权；目标相差不足1%时优先参数更少的候选。没有合格候选时，报告仅选一个诊断展示对象，不能称为验收通过的模型。

新会话固定为2026奥地利站第二次练习赛、车手63、MEDIUM轮胎。会话编号必须由元数据确认，不能猜测。选择按时间最早、至少六个质量合格完整圈的 MEDIUM stint，前三圈仅作一次条件适配，后三圈仅作一次最终评分。干地、旗帜、进出站、删除圈、原始采样覆盖及边界质量控制不使用圈速残差。

条件适配只调整抓地及重放等效动力缩放，各为0.85至1.15，并允许用早圈重新配准坐标和时间；等效动力仍受732.5 kW上限约束。晚圈打开前再次冻结代码、来源和全部配置，独占测试访问记录阻止重复解封。这个实验称为“条件适配后的跨会话测试”。

本次公开访问返回HTTP 401，FP2验收待完成。没有改换会话、车手、轮胎或测试来源。实际回应在 `data/v3/fp2/status.json`。仅离线占位缓存允许冻结前首次联网查询；真实查询记录和已冻结结果保持不可变。已保存实验不能通过换名称绕过测试访问。

## 验收和训练

重放与自主预测分别要求完整圈平均速度 RMSE不超过15 km/h、每圈圈时绝对误差不超过2%、每段绝对误差不超过1秒。10、5、2.5米网格比较使用同一连续路线、参数、驾驶输入、ERS请求和初始条件；5到2.5米圈时差不超过0.10秒、速度曲线差异 RMSE不超过0.5 km/h，并通过物理检查。正式网格为5米的目标间距，闭环均分后的实际间距记录在结果中。

只有数据、收敛、物理、网格、开发和新测试全部通过，才运行数值教师与三个种子的 BC/DAgger。预算沿用第二阶段：600轮BC、三轮DAgger各600轮，种子0、1、2。不扩展SAC。任一门槛失败或待完成，正式训练及收益结论暂停；低轮数学习单元测试不等于正式训练。

质量默认800 kg，825和850 kg仅作冻结参数敏感性分析，不据此选质量。真实燃油、制动压力、SOC、动力分配和精确赛车线未知，所有参数解释为等效模型参数。

## 离线查看与复现

直接打开 `results/austria_2026_v3/report.html` 查看双路径、候选、制动诊断和门槛；页面无需联网。`experiment.json` 保存完整轨迹，CSV包括末端状态、路径及保护原因；末端行不伪造功率。

在项目目录运行以下命令：

```powershell
.\run.ps1 audit-v3
.\run.ps1 verify-v3
.\run.ps1 test
.\run.ps1 serve
```

`verify-v3`只重放本地校准和开发轨迹，逐项比对速度、时间、能量、等效动力、失败状态和被拒绝步的诊断，不再次打开晚圈。准确度门槛与实现复现分别报告。`serve`后打开 `http://127.0.0.1:8765/austria_2026_v3/report.html`。

其他机器使用Python 3.12及固定依赖：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --no-index --find-links vendor/wheels -r requirements-lock.txt
.\.venv\Scripts\python.exe -m f1ers_v3 audit-v3 --offline
.\.venv\Scripts\python.exe -m f1ers_v3 verify-v3
```

下载包包含12个固定依赖wheel，适用于Windows x64与Python 3.12；在该环境首次安装也可离线完成。其他平台需自行取得兼容的固定版本依赖。实验缓存本身可离线使用。解压后的已保存实验应使用 `verify-v3`，不要再次校准或删除访问记录。`run-v3`在没有保存结果的独立第三阶段工作副本中执行完整批准流程，并拒绝覆盖已有 `experiment.json`。真实401状态及已经冻结的结果不会被命令自动刷新。后续同协议续验应保留本次交付包和原始冻结文件，明确取得同一FP2来源缓存及记录状态迁移；当前三个命令不提供自动恢复待验收实验的功能。

```powershell
.\.venv\Scripts\python.exe -m f1ers_v3 run-v3 --offline
```
