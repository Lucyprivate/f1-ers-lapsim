# Spielberg 第二阶段：因果执行与前瞻精度验收

本阶段使用同一逐段状态转移进行训练、数值求解和正式评估。第一阶段完整结果及下载包保留；新版结果位于 `results/austria_2026_v2/`。

| 最大分段绝对误差 | ≤1 s | 1.163 s | 1.031 s |

## 运行与查看

```powershell
.\run.ps1 run-v2
.\run.ps1 verify-v2
.\run.ps1 test
```

`run-v2` 会运行预注册三起点校准，并依据开发集门槛决定是否开展正式学习训练。这个研究协议的测试集只能首次评分一次；已有实验请直接查看 `results/austria_2026_v2/report.html`，使用 `verify-v2` 重放模型与检查来源，无需重新拟合。改结果目录名字也不能重新解封同一测试集。若首次评分中断，开始记录保留，不能通过删除记录继续把该集合声称为新测试。

Windows 环境配置与 Python 3.12 固定依赖见主 README。完整缓存已包含新增公开遥测，依赖配置完成后无需网络即可验证与重放。结果报告自包含；页面视觉和交互是否实测单独列在验证记录中。

## 数据边界与精度门槛

拟合固定使用3–6圈；第一阶段已经查看过的7/9圈改为开发集。第10–12圈是预注册的新遥测测试集，仅按预先冻结的质量规则可用13–18圈依次替补。此次10–12均通过质量筛选，无替补。几何配准与主动空气动力近似仍来自3–6圈，没有用开发或测试圈重新拟合。

新测试为同赛事、同车手、同轮胎 stint 的完整速度/位置遥测留出。候选圈的圈速/分段元数据曾被查看，这不是全未知赛事测试，也不证明新赛道泛化。`load_dataset_v2(..., include_test=False)` 不加载测试数组或标签；配置与权重冻结后只计算一次最终误差。

精度目标在下载新遥测前冻结：完整圈速度 RMSE 的等权均值≤15 km/h，每圈圈速绝对误差≤2%，每段时间绝对误差≤1秒。收敛、物理检查和开发集精度全部通过后才训练；精度未达标时保留诊断并暂停收益结论。该目标属于研究验收要求，与 FIA 法定约束分别报告。

校准只拟合摩擦系数、等效阻力面积和等效下压力面积，ICE功率等假设固定。三个起点分别来自上一阶段拟合值、固定先验及参数边界中点，每个起点最多200次迭代/400次评估。目标函数等权使用归一化速度、整圈与分段残差，并加入固定先验；开发/测试值不进入目标函数。

## 保守电量保护

每个独立单圈从2 MJ开始，全圈保底也是2 MJ，允许容量为4 MJ。部署只能使用本圈已经回收的能量。正功率还保留按100 kW/s降至零所需的储备 `R(P)=P²/(2000r)` MJ；实际段时间下必须满足 `P·dt/1000+R(P)≤E−E_floor`。

功率、时间、电量、机械来源和公开规则子集联合检查。无法找到可认证动作时停止并保存拒绝原因；末端不补电，也不通过未来全圈重放调整部署预算。完整非公开 DOC058/PU初始hold状态机仍未实现；部分公开豁免采用更保守的执行范围。

零 ERS 因果模型先求共同周期边界速度，每个策略从同一起速运行，终点受共同速度上限约束，末速误差≤0.02 m/s才是有效圈。这里的独立重置实验不证明连续多圈能力；保守执行层提供电量保证，神经网络本身的独立保证尚未证明。

## 学习与诊断接口

新增13维观测包含可部署电量余量。模型记录 schema 2、`causal_floor_v2` 协议，旧12维checkpoint用于历史协议。BC/DAgger以同一因果教师轨迹训练，部署时仅执行数值网络。

开发精度通过后的默认预算为：三个种子BC 600轮、最多三轮DAgger各600轮；固定 `α=0.001` 和自动温度的SAC各三个种子、每种子20圈，`gamma=1`。只有某组完整三种子的最佳合法策略相对BC平均改善≥0.05秒，才从BC重新启动该组每种子60圈正式实验。失败/退化候选、Q与实际回报、探索幅度、梯度和动作削减均保留。

## 文件与结果解释

- `config/protocol_austria_2026_v2.json`：下载前冻结的协议。
- `data/v2/manifest.json`：新来源、继承输入与处理文件校验信息。
- `frozen_configuration.json`：测试前冻结的源代码、车辆、数据和模型散列。
- `calibration.json`、`development.json`、`test_evaluation.json`：分别保存拟合、开发与新测试结论。
- `experiment.json`、`summary.json`、`trace_*.csv`：完整轨迹与摘要。CSV包含末端状态行，末端无段功率字段，便于核验最后一段守恒。
- `verification.json`：测试、源代码匹配和独立重放结果；工件完整性与模型精度分别报告。

除协议和数据文件外，以上结果均在同一新版实验目录。真实 SOC、MGU-K功率、ICE与电机的分解以及实际主动空气动力状态仍不可由公开速度唯一识别。二维路线忽略坡度和倾角，本阶段仅保留单赛道、固定车辆/轮胎、干地和Overtake/Boost关闭的条件。
