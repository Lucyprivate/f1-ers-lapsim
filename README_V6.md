# V6 可持续控制研究

这是用户明确授权的本地策略研究。车辆和真实遥测精度放行门槛仍保留；研究训练并不代表模型已达到真实赛车精度。v2/v3/v4/v5 源码、数据和交付保持冻结。仅新增 v6 驾驶、规则、学习和分析层，复用冻结 v4 时间域积分内核。

默认质量 800 kg、等效 ICE 400 kW、理想 DC 电量工作区间 2–4 MJ。参数敏感性不参与选择。正赛 3–6 圈用于结构诊断，7/9 圈只用于最终开发评分，FP2 未打开。控制和奖励均不读取未来观测速度。

## 执行与复现

使用现有离线环境：`./run-v6.ps1 audit-v6`、`./run-v6.ps1 run-v6`、`./run-v6.ps1 verify-v6`、`./run-v6.ps1 test-v6`。也可 `python -m f1ers_v6 <命令> --offline`。正式计算要求干净 Git 工作树，固定源码提交；已有实验不可覆盖。默认输出 `results/austria_2026_v6`，属忽略制品。

预注册 R0–R6 共七轮：旧模型机制审计、动力响应与周期边界、有限数值教师、动作映射与块数、三种子 BC/固定标签 DAgger、固定/自动温度 SAC、MC critic 与能量势函数修正。SAC 最大总预算 180 episode，每种子 60。实际完成数、异常和最优/最后检查点分开保存；BC 回退不能称为 SAC 收敛。

训练和评分使用相同 `CausalEnvV6`/`advance_interval`。正轮端需求允许实际 ICE+K 功率影响速度；预计算几何只提供制动/曲率上界。回收依据真实负轮端需求，不依据负加速度。规则保护查询无副作用，只有接受的子步提交状态。周期速度求解只修改整圈试验初态；圈内没有速度重置或整圈功率缩放。

数值教师是有限控制族中的搜索，不是全局最优证明。每个候选实际连续执行六圈，继承速度、电量、DC 和完整 FSM，只重置每圈回收计数；按最后两圈均时选择通过者。有限连续验证不证明无限时间周期稳定性。正式分段精度计入所有样本；部分圈不评分。原始轮端需求与 ERS 动作被冻结后独立检查输出重采样和内部积分收敛。

`verify-v6` 校验所有日志/失败轨迹/检查点散列，并以相同初态重跑获选策略、校准及开发分段指标。它不重训练 SAC 或重新搜索教师，保存的随机训练结果通过散列验证。离线历史数据与依赖沿用 v5 交付和 `requirements-lock.txt`。

## 规则范围

赛事重现采用 2026-06-25 技术 Issue 19/运动 Issue 7，另记录截至本轮已核对的 Issue 20/9 差异。详见 [RULES_V6.md](RULES_V6.md)。公开功率、回收、窗口、下降速率和保持约束由因果状态机执行；DOC-058 的真实期间定义、真实转速/传动、真实 SOC/损耗与精确气动开关仍未验证。证书始终保留 `full_fia_verified=false`。

350/700/1000 米末段保护是为周期闭合而限制控制族的实验选择，不是 FIA 规则。工程效率 .95/.90 与规则 .97 校正分开。7500 rpm 为声明的模型下界，不能代替真实传动验证。电量是理想 CU-K DC 等效量；50 W 辅助消耗仅作敏感性报告。
