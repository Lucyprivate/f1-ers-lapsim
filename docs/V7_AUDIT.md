# v7 独立审查：边界、可证实结果与剩余误差

本审查在 v7 实验前读取冻结 v6/R7 源码、协议与报告。它是后续实验的验收依据，不表示以下新实验已经运行或通过。默认仍为 800 kg、400 kW 等效 ICE 和 2–4 MJ 理想 DC 等效储能；v4 积分内核及历史交付不改写。

## 已有证据限定了什么

- v6 原保留教师的 70.672492 秒是已测试有限候选中的模型结果；该轨迹连暖态也未通过后来增加的代理一致性检查，不能作为完整放行基准。
- R7 选出的 71.331290 秒暖态通过原公开子集、跨圈携带和附加代理检查；冷态六圈的完整附加检查仍失败。不能丢弃冷圈后宣称全程通过。
- R7 历史开发 7/9 圈的全圈 RMSE 为 18.618326 km/h，分段为 18.272470、18.775493、18.694018 km/h，最大分段圈时误差为 1.600265 秒。正式精度门槛仍失败。
- 原 SAC 共 180 集，没有超过 BC 的保留最佳检查点。两个 Q 接近不能证明 Q 正确；原诊断的 Q 与实测回报仍存在约 32 秒的系统偏差。
- 第 7/9 圈已被反复使用，须称为历史开发数据。第 10–12 圈属于历史诊断；FP2 最终测试仍未打开。

## 学习状态与价值尺度

v6 的 31 维状态没有直接提供 `reference_mechanical_kw` 和 `target_reduction_mechanical_kw`。当有效请求已受能量限制时，历史参考不能从前一实际 DC 可靠推回。

独立合成检查得到：保持阶段、剩余保持 0.75 秒、已削减 20 kW、原请求 150 kW DC、前一实际 200 kW DC、储能 4 MJ 和相同物理状态下，参考/目标 `(250,100)` 与 `(300,150)` 的已发布规则特征完全相同，但下一 0.02 秒请求分别为 242.105263 与 294.736842 kW DC。这证明允许 `RuleState` 域中存在特征别名；尚未证明两个状态都能由真实接受轨迹到达。

新状态应显式包含影响未来的参考、目标和有效需求上界，更新检查点协议。回归验证应让上述两个状态得到不同观察，或提供受限可达域的等价性证据，不能直接复用旧检查点解释新增特征。

固定中性圈时尺度可用于内部 Q 归一化，但奖励、终止罚分、能量势函数和熵系数必须按同一尺度转换，报告时恢复秒。不要加每步常数来替代除以常量，前者可能改变不同 episode 长度的偏好。MC 标签、Bellman 目标、actor 梯度和温度更新须一致。至少用有限差分验证 actor/critic 梯度，并检验常数回报平移或固定倍率是否符合声明。

动作投影的多对一关系会导致原动作与实际供给明显不同。记录原动作、有效请求与执行动作有助于解释。若 Q 使用执行动作，actor 必须正确组合因果投影，且处理投影后的概率与梯度；仅把 replay action 换成执行值而继续用原 actor action 更新，会引入新的动作语义不一致。

## 建议的至少六轮顺序

每轮先冻结代码/配置、运行、读日志，再进入下一轮。下面是实验顺序建议，结果须以后续保存记录为准。

1. 在相同冷态重现 R7 代理失败，记录第一处 NORMAL 可用性下降、第一处 HOLD/LIMITED 差值及能量储备。
2. 修复启动与持续部署的储备管理，使请求下降进入合法保持/下降阶段；禁止沿途重置，复验冷态和暖态。
3. 在修复后的保护器中重新运行数值教师及有因果意义的动作映射，保存所有不完整候选。
4. 以新特征和修复保护器训练或重新验证 BC；保留教师/BC 作为独立比较基准。
5. 对同一固定训练初态比较原秒单位与一致归一化 SAC，并审查 Q 对 MC 的秒单位误差。
6. 对实际物理携带形成的稳态初态训练或评估 SAC，区分初态分布改进和价值尺度改进，再运行冷态六圈及数值细化。

新 SAC 预算必须预注册，单独计数，不能回写原 180 集。无 SAC 改善时继续保留较好的教师/BC，并明确“未证明 SAC 收敛或收益”。六轮只能证明有限族中的比较结果，不能证明全局最快。

## 验收检查

- 每个被排名候选完整保留至少六个连续物理圈；各圈直接携带末速度、储能、DC、削减阶段、参考、目标及保持剩余时间。只允许重新计数每圈回收。
- 每圈末能量不低于圈初，允许的数值误差仍为 `1e-8 MJ`；跨界速度、DC 与完整期间状态均检查。不能只用末两圈均值遮盖冷态失败或累积耗能。
- 冷态至暖态所有圈均通过原公开子集、物理检查及 HOLD/LIMITED 有效请求代理一致性；无交集时终止并保留失败位置。
- 10/5/2.5 米输出与三组内部步细化分别验证。冻结原始需求、策略动作、初态和保护器类型；相邻内部细化的圈时差不超过 0.10 秒、速度 RMSE 不超过 0.5 km/h。
- 部分圈不计算正式圈时、全圈 RMSE 或未完成分段。完整圈分别报告 S1/S2/S3 的速度 RMSE、圈时误差、部署/回收、净能量和账本残差。
- 正式阈值仍为全圈平均 RMSE≤15 km/h、每圈绝对圈时误差≤2%、每段绝对时间误差≤1 秒；重放与自主路径不能互相替代。
- 新实验入口对 FP2 下载、适配、解封、评分接口做拒绝访问回归；记录共享协议身份及账本状态，不获取新评分机会。
- v2–v6 源码、标签、ZIP 和 bundle 散列保持不变。新结果提交与实验 `code_commit` 分开；运行开始工作树干净，原实验不可覆盖。
- 理想 DC 能量闭合、有限跨圈稳定、模型公开子集、完整 FIA、真实 SOC、遥测精度及新会话六个结论分别记录。

## 仅用校准圈的结构诊断

不修改动力学参数或路线也可以增加下列只读证据：

| 假设 | 固定诊断 | 反证或停止条件 |
|---|---|---|
| 线路/曲率导致入弯可行性冲突 | 3–6 圈原始速度、加速度采样区间与冻结曲率，计算联合需求利用率的上下界。 | 区间跨越可行性阈值时记为尚不能辨识；不得把诊断速度反馈进预测。 |
| 直线动力缺口被轮胎参数吸收 | 全油门、非制动、固定低曲率窗口，用观测加速度估计等效轮端功率敏感性区间。 | 未覆盖 400 kW 或未知 ERS 区间不能直接拟合部署策略；参数保持冻结。 |
| 首弯制动请求随剩余能力消失 | 对原制动映射分别记录请求力、能力、接受力、横向利用率、截断原因。 | 需求和能力无法从数据分离时停止解释，不用一项联合力失败指认制动力过大。 |
| 控制线/钟差错误 | 比较固定路线投影与不缩放速度积分；报告冻结全局配准及采样不确定性。 | 不逐圈减首样本、不伸缩距离、不按速度残差移动曲线。 |

以上可复用 v5 校准诊断，不读取开发圈作为结构拟合依据，也不打开 FP2。若精度仍失败，应交付这些不可辨识因素与失败轨迹，不能靠 SAC 更快圈时宣布模型通过。
