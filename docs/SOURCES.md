# Sources and scope

This package uses equivalent model parameters. Observed speed, lap timing, and sector timing differ from simulated power, regeneration, and ideal DC-equivalent energy. Public data do not reveal real brake pressure, ICE/MGU-K allocation or SOC.

- [OpenF1](https://openf1.org/): 2026 Austrian Race, session 11315, driver 63. Calibration used laps 3–6. Historical development repeatedly used laps 7/9. Laps 10–12 are historical diagnostics. The public package excludes telemetry and processed arrays. See [NOTICE.md](../NOTICE.md) for source terms.
- [TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database/tree/e59595d1f3573b30d1ded6a08984935b957688e0): fixed minimum-curvature Spielberg route, not a measured 2026 racing line or a minimum-time solution. The public package excludes data and derived geometry. The model uses a continuous periodic curve and true arc-length mapping, with calibration-only registration.
- [FIA technical regulations, Section C, Issue 19, 2026-06-25](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_c_technical_-_iss_19_-_2026-06-25.pdf): historical rules for the modeled event.
- [FIA sporting regulations, Section B, Issue 07, 2026-06-25](https://www.fia.com/system/files/documents/fia_2026_f1_regulations_-_section_b_sporting_-_iss_07_-_2026-06-25.pdf).
- [Austria Power Unit Information, Doc 5](https://www.fia.com/system/files/decision-document/2026_austrian_grand_prix_-_power_unit_information.pdf) and [circuit map, Doc 7](https://www.fia.com/system/files/decision-document/2026_austrian_grand_prix_-_competition_notes_-_circuit_map_pit_lane_drawing_emergency_exits_map_and_red_zone.pdf): event-specific power and energy constraints and approximate sector/rule coordinates. The package does not redistribute complete official files or rendered pages.

The implementation treats the 350 kW limit as DC power. It keeps the event's 8.0 MJ regeneration limit. It converts the 4326 m official reference distance onto the historical route. Doc 5 and Doc 7 give conflicting circuit lengths. The model uses Doc 7 as a documented choice. Exact FIA ECU periods, exceptions, transmission state and the real efficiency map remain unknown. The audit checks engineering geometry/request safeguards separately from the public rule subset.

The registered cross-session test remains 2026 Austrian FP2, driver 63, MEDIUM. It allows one bounded early-lap adaptation and a single later-lap score. Accuracy gates did not pass. The supported CLI and included tests do not fetch or open those arrays. Internal data helpers keep the original protocol and shared-ledger checks. Calling them is separate from the supported source-only workflow.
